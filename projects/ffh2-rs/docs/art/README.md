# Art direction reference

`mood-board.png` is the user's mood board for the human-play client's look ("Monastic Pixel Noir"):
dark, restricted-palette pixel art; strong silhouettes on near-empty terrain; the map as a
manuscript; muted crimson and pale green reserved for the extraordinary. The board is a style direction and vibe only, not a UX spec: its words, specific symbols,
icons and layout are placeholders from the mock-up tool, not part of the direction. All game art is original
(no Civ4/FFH2 assets); see `docs/ART.md` for the style guide.
